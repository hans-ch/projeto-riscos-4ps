Instalar a Ferramenta Visual (Recomendado: DB Browser for SQLite)
Para visualizar as tabelas, dados e fazer consultas graficamente de forma simples:

Acesse o site oficial: sqlitebrowser.org

Baixe o instalador de acordo com o seu sistema (no Windows, escolha a versão Standard installer for 64-bit Windows).

Complete o assistente de instalação.

Abra o programa e clique em Open Database (Abrir Banco de Dados) para selecionar o arquivo .db gerado pelo seu código Python.
